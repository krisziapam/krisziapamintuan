How I work on projects

This is the process I follow on my school and personal projects.

  1. 01

    Planning and analysis

    Understand the requirements, identify the problem and define what the system should do.

  2. 02

    Design and prototyping

    Prepare wireframes, interface designs, database structures and workflows.

  3. 03

    Development

    Write and organize the code in Visual Studio Code.

  4. 04

    Database integration

    Connect the application to the database and manage its data structures.

  5. 05

    Testing and debugging

    Test features, fix errors, validate inputs and improve usability on a local XAMPP server.

  6. 06

    Hosting and deployment

    Publish projects on hosting such as InfinityFree and GitHub Pages.
