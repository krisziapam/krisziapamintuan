Technologies used in each project

How I build a project

  1. Requirements gathering

    Work out who will use the system and what problem it has to solve.

  2. Planning and systems analysis

    List the features, user roles and data. For e-TALA V2 this became the database design.

  3. UI/UX design and prototyping

    Sketch wireframes and screen layouts before writing the pages.

  4. Development

    Write and organize the code.

    Visual Studio Code · XAMPP

  5. Database integration

    Connect the application to its database and manage the tables.

    MySQL + phpMyAdmin · Supabase · Firebase

  6. Testing and debugging

    Test forms, roles and error cases, and fix what breaks.

    XAMPP (local server)

  7. Deployment

    Publish the project on hosting that fits it.

    InfinityFree · Render · GitHub Pages

  8. Maintenance and improvements

    Keep fixing and improving the project over time.

    GitHub
